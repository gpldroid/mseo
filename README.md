# MSEO AI & Web

منصة عربية ثابتة للمقالات والأدلة العملية حول الذكاء الاصطناعي وتطوير المواقع والبرمجة وتصميم الواجهات وSEO، مع RTL وتجربة قراءة متجاوبة.

## التقنية

- HTML دلالي وصفحات مقالات مستقلة قابلة للفهرسة.
- Bulma كأساس للتخطيط والمكونات عند استخدامه، مع CSS مخصص يحافظ على هوية MSEO العربية.
- JavaScript ES modules مقسّم حسب المسؤولية، من دون إطار عمل تطبيق ثقيل.
- فهرس مقالات JSON يُولّد آليًا، وخريطة موقع وأدوات تحقق.
- GitHub Pages للنشر الثابت؛ لا يحتاج المشروع إلى backend لتشغيل الصفحات الحالية.

## تنظيم المشروع

راجع [معمارية المشروع](docs/architecture.md)، و[نظام التصميم](docs/design-system.md)، و[خطة المحتوى](docs/editorial-roadmap.md).

## التطوير والتحقق

يتطلب Node.js LTS وnpm.

```sh
npm ci
npm test
npm run build
```

لا تعدّل ملفات catalogue أو sitemap المولدة يدويًا. بعد البناء، راجع الفروقات وتأكد من أن الروابط القانونية والبيانات المنظمة ومحتوى المقالات لم تتغير دون قصد.
