# MSEO AI & Web

منصة عربية ثابتة للمقالات والأدلة العملية حول الذكاء الاصطناعي وتطوير المواقع والبرمجة وتصميم الواجهات وSEO، مع دعم RTL وتجربة قراءة متجاوبة.

## التقنية

- صفحات HTML مستقلة وقابلة للفهرسة.
- **CSS عام موحد:** `assets/css/style.css`.
- **JavaScript عام موحد:** `assets/js/site.js`، ويضم الرأس والتذييل والمظهر واللغة والتنقل والبحث وفهرس الصفحة الرئيسية والأرشيف وإشعار الخصوصية.
- فهرس مقالات JSON وخريطة موقع يتم توليدهما آليًا.
- GitHub Pages للموقع الثابت.
- لوحة الإدارة منفصلة في `admin-dashboard/` للحفاظ على عزل المصادقة والصلاحيات وعمليات إدارة المحتوى.

## تنظيم المشروع

راجع [معمارية المشروع](ARCHITECTURE.md)، و[نظام التصميم](docs/design-system.md)، و[خطة المحتوى](docs/editorial-roadmap.md).

## التطوير والتحقق

يتطلب Node.js 22 أو أحدث وnpm.

```sh
npm ci
npm test
npm run build
```

لا تعدّل ملفات الفهرس أو خريطة الموقع المولدة يدويًا. لا تعتبر النشر مكتملًا حتى ينجح فحص GitHub Actions ويتم التحقق من الموقع الحي.
