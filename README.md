# MSEO AI & Web

منصة عربية ثابتة للمقالات والأدلة العملية حول الذكاء الاصطناعي وتطوير المواقع والبرمجة وSEO، مصممة باتجاه RTL وتجربة متجاوبة للهواتف والحواسيب.

## التقنيات

- HTML دلالي وصفحات مقالات مستقلة قابلة للفهرسة.
- CSS design system مشترك مع tokens للون والطباعة والمسافات والحركة.
- JavaScript ES modules بدون إطار عمل ثقيل.
- JSON catalogue للمقالات، مع سكربتات Node.js لبناء الفهرس وخريطة الموقع والتحقق.
- GitHub Pages للنشر الثابت.

## هيكل المشروع

راجع [ARCHITECTURE.md](ARCHITECTURE.md) و[خريطة الملفات](docs/architecture.md).

## التطوير والتحقق

يتطلب Node.js LTS وnpm.

```sh
npm ci
npm run validate
npm run build
```

يجب مراجعة التغييرات الناتجة عن بناء فهرس المقالات وsitemap قبل النشر.

## ملاحظة حول Java

هذا مشروع موقع ثابت، لذا Java ليست مطلوبة لتشغيله. JavaScript هي لغة التفاعل داخل المتصفح. لا نضيف خادم Java إلا عند وجود متطلبات backend فعلية لا يستطيع GitHub Pages تنفيذها.
