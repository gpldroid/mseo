# MSEO AI & Web

منصة عربية ثابتة للمقالات والأدلة العملية حول الذكاء الاصطناعي وتطوير المواقع والبرمجة وتصميم الواجهات وSEO، مع واجهة RTL وتجربة قراءة مريحة على الهاتف والحاسوب.

## التقنية والقرارات

- HTML دلالي وصفحات مقالات مستقلة قابلة للفهرسة.
- CSS مشترك مع Design Tokens للطباعة والألوان والمسافات والحركة.
- JavaScript ES modules مقسّم إلى وحدات صغيرة.
- JSON catalogue للمقالات، وسكربتات Node.js لبناء الفهرس وخريطة الموقع والتحقق.
- GitHub Pages للنشر الثابت.
- خط Noto Sans Arabic للنصوص، Cairo للعناوين، وIBM Plex Mono للأكواد.
- Font Awesome Free للأيقونات مع توحيد النمط وإرشادات الوصول.

**لا نحتاج Bootstrap في هذه المرحلة.** نريد هوية تحريرية عربية مخصصة لا قالب Bootstrap تقليديًا. كما لا نحتاج Java backend لموقع GitHub Pages ثابت؛ التفاعل داخل المتصفح مكتوب بـ JavaScript. إذا توسع الموقع كثيرًا وأصبحت إدارة المقالات والقوالب يدويًا مرهقة، يمكن تقييم Astro مع Content Collections دون تغيير الهوية البصرية.
