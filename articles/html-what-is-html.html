ما هي لغة HTML؟ دليل البداية لبناء أول صفحة ويب

تعرف على لغة HTML ودورها في بناء صفحات الويب، وكيف تكتب أول ملف HTML وتشغّله في المتصفح خطوة بخطوة، مع أمثلة عملية للمبتدئين.

ما هي HTML؟

HTML اختصار لـ HyperText Markup Language، أي لغة ترميز النص التشعبي. تستخدم لوصف بنية محتوى صفحة الويب: العناوين، والفقرات، والروابط، والصور، والجداول، والنماذج. هي ليست لغة برمجة بالمعنى المعتاد؛ فهي لا تنفذ منطقًا مثل الحلقات والشروط، بل تحدد معنى المحتوى وترتيبه.

تخيّل موقعًا كمنزل: HTML تحدد الغرف وما تحتويه، وCSS تهتم بالمظهر والألوان، أما JavaScript فتضيف التفاعل والسلوك.

ما الذي تحتاجه للبدء؟

يكفي محرر نصوص ومتصفح حديث. أنشئ مجلدًا باسم html-learning، ثم أنشئ داخله ملفًا اسمه index.html. تأكد أن امتداد الملف هو .html وليس .txt.

أول صفحة HTML لك

<!doctype html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>صفحتي الأولى</title>
</head>
<body>
  <h1>مرحبًا بالعالم</h1>
  <p>هذه أول صفحة ويب أبنيها باستخدام HTML.</p>
</body>
</html>

احفظ الملف وافتحه في المتصفح. ستظهر صفحة بعنوان رئيسي وفقرة. عند تعديل النص وحفظ الملف، حدّث المتصفح لمشاهدة التغيير.

ماذا تعني الوسوم الأساسية؟

  • <!doctype html>: يخبر المتصفح باستخدام معيار HTML الحديث.
  • <html>: يحتوي المستند كله. تحدد lang="ar" لغة المحتوى، وتحدد dir="rtl" اتجاه الكتابة من اليمين إلى اليسار.
  • <head>: يضم معلومات الصفحة التي لا تظهر عادةً ضمن محتواها، مثل العنوان والترميز.
  • <body>: يضم المحتوى المرئي للمستخدم.
  • <h1>: العنوان الرئيسي، و<p>: فقرة نصية.

أخطاء شائعة عند البداية

  • نسيان امتداد .html أو حفظ الملف في مجلد مختلف.
  • كتابة محتوى الصفحة خارج عنصر body.
  • استخدام HTML لتنسيق الألوان والمسافات بدل ترك هذه المهمة إلى CSS.
  • إهمال تحديد لغة الصفحة، ما قد يربك أدوات النطق والتعرف على اللغة.

تمرين عملي

أنشئ صفحة تعريفية قصيرة عن نفسك تحتوي عنوانًا رئيسيًا، وفقرتين، وعنوان تبويب مناسبًا. افتحها في المتصفح وتأكد من ظهور النص العربي واتجاهه بشكل صحيح.

ماذا بعد؟

في الدرس التالي ستتعلم بنية مستند HTML بالتفصيل، وكيف تنظم معلومات الصفحة داخل head والمحتوى داخل body.

كيف تبدأ تطبيق HTML عمليًا؟

ابدأ بصفحة صغيرة تحتوي عنوانًا رئيسيًا وفقرة ورابطًا وصورة ذات نص بديل. افتحها في المتصفح، ثم افحص المصدر وأدوات المطور لتلاحظ كيف تتحول العلامات إلى شجرة عناصر. أضف كل مرة مفهومًا واحدًا حتى تستطيع معرفة سبب أي تغيير.

<!doctype html>
<html lang="ar" dir="rtl">
<head><meta charset="utf-8"><title>صفحتي الأولى</title></head>
<body>
  <main><h1>مرحبًا بالعالم</h1><p>هذه أول صفحة HTML لي.</p></main>
</body>
</html>

خطة تعلم قصيرة

  • تعلم بنية المستند والعناوين والفقرات والروابط.
  • أضف الصور والقوائم ثم النماذج والجداول.
  • استخدم العناصر الدلالية وأجرِ اختبارًا بلوحة المفاتيح.
  • تحقق من HTML قبل إضافة CSS وJavaScript تدريجيًا.
