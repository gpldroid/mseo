أنواع حقول HTML المتقدمة: date وnumber وcheckbox وradio

تعرف إلى أنواع input المناسبة لاختيار التاريخ والأرقام والخيارات المتعددة والاختيار الأحادي مع أمثلة واضحة.

اختيار نوع الحقل

يؤثر نوع input في لوحة المفاتيح على الأجهزة المحمولة وفي أدوات المتصفح للتحقق والتعامل مع البيانات. اختر النوع الذي يناسب المعنى الفعلي للبيانات، لا المظهر فقط.

التاريخ والأرقام

<label for="start-date">تاريخ البداية</label>
<input id="start-date" name="start-date" type="date" required>
<label for="seats">عدد المقاعد</label>
<input id="seats" name="seats" type="number" min="1" max="12" step="1">

قد يختلف شكل منتقي التاريخ بين المتصفحات والأنظمة. لا تستخدم number للرموز أو أرقام الهاتف التي لا تُجرى عليها عمليات حسابية.

checkbox وradio

<fieldset>
  <legend>طرق التواصل المفضلة</legend>
  <label><input type="checkbox" name="contact" value="email"> البريد الإلكتروني</label>
  <label><input type="checkbox" name="contact" value="phone"> الهاتف</label>
</fieldset>
<fieldset>
  <legend>نوع الحساب</legend>
  <label><input type="radio" name="account" value="personal" required> شخصي</label>
  <label><input type="radio" name="account" value="business"> أعمال</label>
</fieldset>

يسمح checkbox باختيار عدة قيم، أما radio فيستخدم الاسم نفسه للمجموعة كي يكون الاختيار واحدًا. يضيف fieldset وlegend سياقًا واضحًا للمجموعة.

قواعد التحقق

تساعد خصائص مثل min وmax وstep وrequired على التحقق في المتصفح، لكنها لا تغني عن التحقق على الخادم. اختبر الحالات الحدية ورسائل الخطأ بلوحة المفاتيح وعلى أحجام شاشة مختلفة.
