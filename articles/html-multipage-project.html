مشروع HTML متكامل للمبتدئين: بناء موقع من عدة صفحات

طبّق دروس HTML في مشروع صغير متعدد الصفحات يتضمن التنقل والمقالات والصور ونموذج تواصل وبنية قابلة للصيانة.

فكرة المشروع

سننشئ موقعًا تعليميًا صغيرًا من ثلاث صفحات: الرئيسية، صفحة المقالات، وصفحة التواصل. الهدف التدرب على البنية والروابط والنماذج وإمكانية الوصول، وليس إنشاء نظام خلفي كامل.

تنظيم الملفات

my-site/
  index.html
  articles/
    index.html
    first-lesson.html
  contact.html
  assets/
    css/style.css
    images/

قالب الصفحة

<!doctype html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>موقعي التعليمي</title>
  <meta name="description" content="موقع تعليمي يقدم دروسًا عملية للمبتدئين.">
  <link rel="stylesheet" href="assets/css/style.css">
</head>
<body>
  <header><a href="index.html">الرئيسية</a></header>
  <main><h1>مرحبًا بك</h1><p>ابدأ باستكشاف الدروس.</p></main>
  <footer>معلومات الموقع</footer>
</body>
</html>

المسارات في المثال صحيحة لصفحة الجذر فقط؛ داخل مجلد articles تحتاج غالبًا إلى ../assets/... أو روابط نسبية ملائمة لموضع الملف.

التنقل والروابط

أضف قائمة تنقل دلالية باستخدام nav، واكتب نصوص روابط تصف الوجهة. اختبر كل رابط بعد نقل الملفات، وتجنب الاعتماد على مسارات تعمل محليًا فقط أو على حالة أحرف مختلفة بين أنظمة التشغيل.

صفحة التواصل

<form action="/contact" method="post">
  <label for="name">الاسم</label>
  <input id="name" name="name" autocomplete="name" required>
  <label for="email">البريد الإلكتروني</label>
  <input id="email" name="email" type="email" autocomplete="email" required>
  <button type="submit">إرسال</button>
</form>

هذا النموذج يحتاج إلى خادم أو خدمة نماذج تستقبل الطلبات؛ HTML وحدها لا ترسل الرسائل إلى بريدك.

قائمة التسليم

  • لكل صفحة عنوان ووصف وH1 واضح.
  • كل الصور لها نص بديل مناسب وأبعاد محددة.
  • التنقل يعمل بلوحة المفاتيح وعلى الهاتف.
  • الروابط والملفات لا تعيد أخطاء.
  • اختبر الصفحات باستخدام مدقق HTML، ثم راجع التصميم والتباين.

بعد إنهاء المشروع، ارجع إلى درس بنية المستند ودرس النماذج لتحسين التفاصيل.
