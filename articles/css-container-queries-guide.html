CSS Container Queries: تصميم مكونات تتكيف مع المساحة المتاحة

شرح عملي لـ container-type و@container لبناء بطاقات ومكونات تتكيف مع عرض الحاوية بدل عرض الشاشة فقط.

لماذا نحتاج Container Queries؟

تقيس media queries خصائص نافذة المتصفح غالبًا، بينما قد يوضع المكوّن نفسه داخل شريط جانبي ضيق أو مساحة عريضة في الصفحة. هنا تظهر فائدة Container Queries؛ إذ يمكنها تعديل تنسيق المكوّن وفق المساحة التي تمنحها له الحاوية، لا وفق عرض الشاشة وحده. وهذا يسهل إعادة استخدام المكوّن في أماكن مختلفة.

تعريف حاوية للاستعلام

ضع الخاصية container-type: inline-size على العنصر الذي سيعمل حاويةً للاستعلام. بذلك يصبح بالإمكان تقييم عرض الحاوية على المحور المضمّن واستخدامه لتحديد التنسيق المناسب.

مثال عملي

.product-card-wrapper {
  container-type: inline-size;
}

.product-card {
  display: grid;
  gap: 1rem;
}

@container (min-width: 34rem) {
  .product-card {
    grid-template-columns: 9rem 1fr;
    align-items: center;
  }
}
عندما تتوفر مساحة كافية داخل الحاوية، يعرض المثال البطاقة في عمودين بدل التخطيط الواحد. تأكد من أن العنصر الذي تريد تنسيقه يقع داخل الحاوية الصحيحة، وأن شرط الاستعلام مرتبط بالحاوية المقصودة.

كيف تختلف عن Media Queries؟

اختر media queries للقرارات المرتبطة بالشاشة أو بإعدادات المستخدم، مثل تفضيل تقليل الحركة. أما إذا كان المطلوب تغيير المكوّن بحسب المساحة المتاحة له داخل التخطيط، فـcontainer queries أنسب. ويمكنك الجمع بين النوعين عندما يتطلب التصميم ذلك.

أخطاء شائعة

لا تجعل كل عنصر حاوية للاستعلامات دون سبب؛ حدّد المكوّنات التي تحتاج فعلًا إلى الاستجابة لحجمها. اختبر العروض المتوسطة أيضًا، وتحقق من عدم قص المحتوى أو ظهور تمرير أفقي. تذكّر أن بعض أشكال containment تؤثر في سلوك التخطيط، لذا افحص النتيجة داخل الصفحة الفعلية.

اختبار المكوّن في أماكن متعددة

اختبر البطاقة داخل شبكة كبيرة، ثم في عمود جانبي وعلى شاشة هاتف. غيّر عرض الحاوية مع إبقاء نافذة المتصفح بالحجم نفسه؛ فإذا تغيّر التنسيق تبعًا للحاوية، فهذا يؤكد أن المكوّن يستجيب للمساحة المخصصة له.

الخلاصة

تمنحك Container Queries طريقة عملية لبناء مكوّنات مرنة قابلة لإعادة الاستخدام. ابدأ بمكوّن بسيط، واجعل نقاط التحول مرتبطة بما يحتاجه المحتوى من مساحة، لا بتصنيفات الأجهزة، ثم جرّبه في أكثر من تخطيط.
