خصائص HTML العامة: id وclass وlang وdata-* وhidden

شرح الخصائص العامة التي يمكن استخدامها مع عناصر HTML لتنظيم المحتوى وربطه بالأنماط والسلوك البرمجي.

ما الخصائص العامة؟

الخصائص العامة يمكن استخدامها على عدد كبير من عناصر HTML، مع مراعاة أن لكل خاصية قواعدها. وهي تساعد في تعريف العناصر أو توضيح اللغة أو إضافة معلومات يحتاجها CSS وJavaScript.

خصائص شائعة

  • id: معرّف فريد داخل المستند.
  • class: مجموعة أسماء لتطبيق أنماط أو تحديد عناصر.
  • lang: اللغة المستخدمة في النص، مثل lang="ar".
  • dir: اتجاه النص مثل rtl أو ltr.
  • title: معلومات إضافية عند الحاجة، لكنه ليس بديلًا عن تسمية مرئية.
  • hidden: يخفي المحتوى من العرض المعتاد.
<article id="lesson-3" class="lesson-card" lang="ar" dir="rtl" data-level="beginner">
  <h2>درس للمبتدئين</h2>
</article>

استخدام data-*

يمكن تخزين بيانات مخصصة في خصائص مثل data-level ثم قراءتها من JavaScript عبر element.dataset.level. استخدمها للبيانات غير الحساسة التي تخص العنصر، وليس لكلمات المرور أو الأسرار أو الصلاحيات.

أخطاء شائعة

لا تكرر قيمة id في الصفحة؛ قد يؤدي ذلك إلى سلوك ملتبس في الروابط والبرمجة. لا تستخدم hidden لإخفاء معلومات ينبغي أن تبقى متاحة للمستخدم، ولا تعتمد على title وحده لتوفير تعليمات مهمة.

قاعدة عملية

أضف الخاصية عندما تخدم معنى أو وظيفة واضحة. الخصائص الزائدة تزيد التعقيد ولا تجعل الصفحة أفضل تلقائيًا.
