TypeScript للمبتدئين: تعلّم الأنواع واكتب JavaScript بأخطاء أقل

مدخل عملي إلى TypeScript يشرح الأنواع الأساسية والواجهات والدوال وكيفية تشغيل فحص الأنواع ضمن مشروع JavaScript.

ما TypeScript؟

TypeScript يضيف نظام أنواع ثابتًا أثناء التطوير ثم يُحوّل إلى JavaScript. يساعد على اكتشاف بعض الأخطاء قبل التشغيل ويوفر إكمالًا أفضل في المحرر، لكنه لا يتحقق تلقائيًا من البيانات الخارجية أثناء التشغيل.

الأنواع الأساسية

مثال: 

let userName: string = "Imad";
let articleCount: number = 10;
let isPublished: boolean = true;
يستطيع TypeScript غالبًا استنتاج النوع من القيمة الابتدائية، لذلك اكتب النوع صراحة عندما يوضح عقدًا مهمًا.

أنواع الدوال والكائنات

function formatTitle(title: string, maxLength: number): string {
  return title.slice(0, maxLength);
}
استخدم interface أو type لوصف شكل الكائنات، مثل حقول المقال وعنوانه ورابطه وحالة النشر. هذا يجعل العقود أوضح ويقلل أخطاء الكتابة.

تجنب any وتحقق من البيانات

صرّح بالقيم المحتمل غيابها واستخدم strictNullChecks. لا تستخدم any في كل مكان لأنه يعطّل فائدة الفحص. بيانات JSON القادمة من API تحتاج إلى تحقق وقت التشغيل؛ أنواع TypeScript تُزال عند التحويل ولا تمنع وحدها مدخلات غير صالحة.

أدخل TypeScript تدريجيًا

ابدأ بإعداد مشروع مناسب وشغّل فحص الأنواع ضمن أوامر التطوير والاختبار. في قاعدة كود قائمة، حوّل الوحدات تدريجيًا بدل تغيير كل الملفات دفعة واحدة. استخدم الاختبارات ومراجعة الكود إلى جانب الأنواع، فهي لا تكتشف كل الأخطاء.
