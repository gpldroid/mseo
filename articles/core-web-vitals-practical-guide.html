ما هي Core Web Vitals؟ وكيف تحسّن نتائج موقعك خطوة بخطوة؟

شرح عملي لمقاييس Core Web Vitals: LCP وINP وCLS، وكيفية قياسها وتحديد أولويات إصلاح المشكلات.

المقاييس الثلاثة

تركز Core Web Vitals على ظهور المحتوى الرئيسي (LCP)، والاستجابة للتفاعلات (INP)، واستقرار التخطيط (CLS). هذه المقاييس مهمة لكنها لا تختصر جودة الموقع كله؛ يجب النظر أيضًا إلى المحتوى وإمكانية الوصول وسهولة الاستخدام.

حسّن LCP

حدّد أكبر عنصر مرئي في الصفحة. قد يتأثر بزمن استجابة الخادم، أو تأخر اكتشاف الصورة، أو حجم المورد، أو CSS الذي يمنع العرض. أعطِ الأولوية للمورد الرئيسي وتأكد من أن حجمه مناسب بدل البدء بعناصر صغيرة لا تؤثر في النتيجة.

حسّن INP

قد تتأثر الاستجابة بمهام JavaScript الطويلة أو تحديثات الواجهة المكلفة. قلّل العمل غير الضروري، وقسّم المهام الثقيلة، واجعل التغييرات بعد النقر أو إدخال النص خفيفة. لا يكفي أن يبدو الزر سريعًا إذا كانت الواجهة لا تستجيب.

حسّن CLS وقِس مجددًا

حدّد أبعاد الصور واحجز مساحة للعناصر التي تُحمّل لاحقًا، وتجنب إدراج محتوى أعلى النص بعد بدء القراءة. استخدم PageSpeed Insights للتمييز بين بيانات المختبر وبيانات المستخدمين الفعلية عندما تتوفر، ثم أعد الاختبار بعد التغييرات. راجع دليل تحسين السرعة.

الخلاصة: ابدأ بخطوة قابلة للقياس
