نشر موقع HTML وCSS وJavaScript على GitHub Pages خطوة بخطوة

دليل عملي لنشر موقع ثابت على GitHub Pages، تنظيم الملفات، ضبط المسارات، إضافة sitemap وrobots وتحسين قابلية الفهرسة.

هيكل مشروع مناسب

استخدم index.html للصفحة الرئيسية، مجلد articles للمقالات، pages للصفحات الثابتة، assets للصور وCSS وJavaScript. هذا التنظيم يجعل المشروع أسهل للصيانة.

المسارات النسبية

تأكد من أن الروابط تعمل من الجذر ومن داخل مجلد المقالات. من داخل articles استخدم ../assets للوصول إلى الموارد المشتركة.

GitHub Pages

ارفع الملفات إلى المستودع، ثم فعّل GitHub Pages من إعدادات Pages واختر المصدر المناسب. بعد النشر اختبر الموقع من رابط HTTPS النهائي.

SEO الفني

أضف title وmeta description وcanonical وOpen Graph وبيانات منظمة لكل مقال، وأنشئ sitemap.xml وrobots.txt. يجب أن تعكس البيانات المحتوى الفعلي.

الصور والسرعة

استخدم صورًا بالحجم المناسب، lazy loading للصور غير الحرجة، وقلل الملفات غير الضرورية. لا تعتمد على أرقام افتراضية؛ اختبر الأداء فعليًا.

الخلاصة

الموقع الثابت يمكن أن يكون سريعًا وقابلًا للفهرسة إذا كانت بنية HTML واضحة، الروابط صحيحة، والصفحات تحمل قيمة حقيقية.

  • GitHub Pages custom domains
  • Google Search Central
