دليل CSS Flexbox: ترتيب العناصر ومحاذاتها بسهولة

تعلم CSS Flexbox خطوة بخطوة لفهم المحورين والمحاذاة والمسافات وترتيب العناصر، مع أمثلة عملية لتصميم شريط تنقل وبطاقات مرنة.

ما هو Flexbox؟

Flexbox نظام تخطيط أحادي البعد في CSS، يساعدك على ترتيب العناصر في صف أو عمود والتحكم في محاذاتها وتوزيع المساحة. يناسب أشرطة التنقل ومجموعات الأزرار والبطاقات.

تفعيل Flexbox

.toolbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 1rem;
}

تُطبّق الخصائص على الحاوية الأب. تحدد display: flex التخطيط، وتتحكم align-items في المحاذاة على المحور العرضي، بينما توزع justify-content العناصر على المحور الرئيسي. وتضيف gap مسافة موحدة بينها.

إنشاء بطاقات مرنة

.card-list {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.card {
  flex: 1 1 16rem;
}

تسمح flex-wrap للعناصر بالانتقال إلى سطر جديد عندما تضيق المساحة. وتعطي flex: 1 1 16rem كل بطاقة أساسًا مرنًا يسمح لها بالنمو والانكماش.

فهم المحورين

المحور الرئيسي يتبع قيمة flex-direction. عند استخدام row يكون أفقيًا في اتجاه الكتابة المعتاد، وعند استخدام column يصبح رأسيًا. لذلك يتغير تأثير المحاذاة بحسب اتجاه الحاوية.

أخطاء شائعة

  • الخلط بين justify-content وalign-items.
  • استخدام هوامش متعددة بدلًا من gap حيث تكون مناسبة.
  • عدم اختبار النصوص الطويلة على الشاشات الصغيرة.

متى تختار Grid بدلًا منه؟

استخدم Flexbox عندما يكون التخطيط في محور واحد هو المطلوب. أما إذا احتجت إلى التحكم في صفوف وأعمدة مترابطة معًا، فقد يكون CSS Grid أنسب. ويمكن الجمع بين التقنيتين في الصفحة نفسها.
