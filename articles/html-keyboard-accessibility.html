إمكانية الوصول في HTML: لوحة المفاتيح والتركيز وقارئات الشاشة

خطوات عملية لتحسين وصول صفحات HTML باستخدام العناصر الأصلية وتسميات واضحة وترتيب تركيز منطقي.

ابدأ بالعناصر الأصلية

العناصر الأصلية مثل button وa وinput توفر سلوكًا مألوفًا للوحة المفاتيح وتقنيات الوصول. لا تستخدم div قابلًا للنقر بديلًا عنها دون سبب قوي.

التسميات والعناوين

اربط كل حقل بتسمية واضحة باستخدام label، واستخدم العناوين بترتيب منطقي يساعد على تصفح أقسام الصفحة. أضف نصًا بديلًا للصور ذات المعنى، واتركه فارغًا للصورة الزخرفية.

التركيز بلوحة المفاتيح

a:focus-visible, button:focus-visible, input:focus-visible {
  outline: 3px solid #2563eb;
  outline-offset: 3px;
}

لا تزل مؤشر التركيز دون بديل واضح. جرّب التنقل باستخدام Tab وShift+Tab وEnter وSpace، وتأكد من أن ترتيب التركيز يتبع ترتيب القراءة وأن المستخدم لا يُحتجز داخل عنصر.

اللغة والاتجاه

حدد لغة المستند عبر lang="ar" واتجاهه عبر dir="rtl" عندما يكون المحتوى عربيًا. عند تضمين نص بلغة أخرى، عرّف لغته إن كان ذلك يساعد النطق بقارئ الشاشة.

اختبارات عملية

  • تصفح الصفحة دون فأرة.
  • تحقق من وضوح التركيز والتباين.
  • اختبر النماذج ورسائل الأخطاء.
  • استخدم أداة تدقيق آلي مع اختبار يدوي؛ لا تكفي نتيجة الأداة وحدها لإثبات الوصول الكامل.

تابع سلسلة HTML

اختبار الوصول بلوحة المفاتيح

ابدأ بالضغط على Tab للتنقل بين العناصر التفاعلية، واستخدم Shift+Tab للعودة، وEnter أو Space لتفعيل الأزرار بحسب سلوكها الطبيعي. يجب أن يكون ترتيب التركيز منطقيًا، وأن يكون مؤشر التركيز مرئيًا، وألا يقع المستخدم داخل نافذة أو قائمة دون وسيلة واضحة للخروج.

button:focus-visible,
a:focus-visible,
input:focus-visible {
  outline: 3px solid #2563eb;
  outline-offset: 3px;
}

لا تزل مخطط التركيز باستخدام outline: none دون توفير بديل واضح. استخدم عناصر HTML الأصلية قبل بناء عناصر تفاعلية مخصصة، لأنها تقدم سلوك لوحة المفاتيح المتوقع افتراضيًا.

مراجعة سريعة

  • كل وظيفة يمكن الوصول إليها بالفأرة يمكن الوصول إليها بلوحة المفاتيح.
  • لا توجد مصيدة تركيز داخل القوائم والنوافذ.
  • التسميات والتعليمات ورسائل الخطأ مفهومة دون الاعتماد على اللون وحده.

اختبار التركيز والتنقل

ابدأ من أعلى الصفحة واضغط Tab ثم Shift+Tab، وتأكد أن ترتيب التركيز يطابق ترتيب القراءة. يجب أن يكون العنصر النشط واضحًا بصريًا، وألا يُنقل التركيز إلى عناصر مخفية أو غير قابلة للاستخدام. لا تستخدم tabindex بقيم موجبة لإعادة ترتيب الصفحة؛ أصلح ترتيب DOM أو تصميم المكوّن بدل ذلك.

  • تأكد أن كل وظيفة متاحة بالفأرة متاحة بلوحة المفاتيح.
  • استخدم زرًا للإجراءات ورابطًا للتنقل.
  • أضف رابط تجاوز إلى المحتوى عند وجود رأس تنقل طويل.
  • لا تزل outline دون توفير مؤشر تركيز بديل واضح.

اختبر النوافذ المنبثقة والقوائم أيضًا، وتأكد من عودة التركيز إلى العنصر الذي فتح المكوّن بعد إغلاقه.
