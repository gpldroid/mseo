محلل SEO الأساسي

افحص عناصر الصفحة المهمة لمحركات البحث واحصل على ملاحظات واضحة يمكنك تطبيقها مباشرةً. كل التحليل يجري داخل متصفحك.

🔒خصوصيتك أولًا: لا نرفع HTML ولا نجلب الرابط الذي تدخله. حلّل كود الصفحة أو ملف HTML محفوظًا على جهازك.
ابدأ الفحص

أدخل HTML الخاص بصفحتك

افتح مصدر الصفحة في متصفحك وانسخ HTML، أو اختر ملفًا محليًا بصيغة HTML.

يُستخدم فقط لتمييز الروابط الداخلية والخارجية؛ لن يتم فتح الرابط.

ألصق HTML أو اختر ملفًا ثم ابدأ التحليل.

تقرير التحليل

دليل عملي

كيف تحسّن SEO لصفحتك؟

استخدم النتائج كبداية للمراجعة، ثم قيّم المحتوى وتجربة الزائر والسياق الفعلي للصفحة.

01

اكتب عنوانًا محددًا

اجعل لكل صفحة عنوانًا واضحًا وفريدًا يصف المحتوى. ضع الموضوع الأساسي بصورة طبيعية وتجنب تكرار الكلمات المفتاحية أو الوعود المضللة.

02

أنشئ وصفًا مفيدًا

لخّص فائدة الصفحة بلغة بشرية وميّزها عن الصفحات الأخرى. قد تعرض محركات البحث مقتطفًا مختلفًا؛ الطول وحده لا يضمن ظهور الوصف كما هو.

03

نظّم العناوين

استخدم H1 لعنوان المحتوى الرئيسي، ثم H2 للأقسام وH3 للأقسام الفرعية عند الحاجة. حافظ على تسلسل منطقي يسهل فهم البنية.

04

راجع الفهرسة وcanonical

تحقق من عدم وجود noindex غير مقصود، وأن canonical يشير إلى النسخة المفضلة الصحيحة. افحص أيضًا robots.txt واستجابة الخادم؛ هذه الأداة لا تؤكدها.

05

حسّن الصور والروابط

اكتب alt يصف وظيفة الصورة ذات المعنى، واجعل alt فارغًا للزخارف البحتة. استخدم نصوص روابط واضحة، واختبر الروابط بأداة تتصل بالشبكة لإيجاد المكسور.

06

اهتم بالمحتوى وتجربة الصفحة

أجب عن حاجة الزائر بوضوح وأضف معلومات أصلية ومصادر موثوقة حيث تلزم. اختبر الأداء وإمكانية الوصول وتجربة الهاتف بأدوات منفصلة؛ عدد الكلمات ليس هدفًا مستقلًا.

ما الذي لا يقيسه هذا الفاحص؟

لا يختبر ترتيب الصفحة أو الروابط الحية أو HTTP status أو Core Web Vitals أو محتوى JavaScript بعد التحميل أو قواعد الفهرسة الفعلية لدى Google. الدرجة تقريبية وليست مقياسًا رسميًا.

الأسئلة الشائعة

هل يحلل الأداة رابط موقعي مباشرةً؟

لا. ألصق HTML أو حمّل ملفًا محليًا. جلب المواقع من المتصفح قد يُمنع بواسطة CORS، وتجنب الجلب يحافظ على خصوصية محتواك.

هل تعني درجة 100 أن الصفحة ستتصدر نتائج البحث؟

لا. الدرجة قائمة تحقق صغيرة للعناصر التي يمكن قراءتها من HTML فقط. الترتيب يعتمد على عوامل كثيرة ولا توجد درجة تضمنه.

هل هناك طول مثالي إلزامي للعنوان والوصف؟

لا يوجد حد ثابت يضمن الظهور الكامل. الأرقام إشارات تحريرية تقريبية؛ الأولوية للوضوح والدقة وتلبية نية الباحث.

هل يتم حفظ الكود أو إرساله إلى جهة خارجية؟

لا ترسل هذه الصفحة HTML إلى خادم التحليل؛ المعالجة محلية في المتصفح. لا تلصق بيانات سرية في أي أداة ويب ما لم تكن واثقًا من سياسة الخصوصية.
