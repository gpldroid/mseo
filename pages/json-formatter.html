كيف تستخدم منسّق JSON؟

JSON صيغة شائعة لتبادل البيانات بين الواجهات البرمجية والتطبيقات. يجب أن تكون القيم والمفاتيح النصية محاطة بعلامات اقتباس مزدوجة.

01

التنسيق

أضف المسافات والأسطر لتسهيل قراءة الكائنات والمصفوفات وفهم بنية البيانات.

02

الضغط

أزل المسافات غير الضرورية لإنتاج JSON مختصر مناسب للنقل أو التخزين.

03

التحقق

تحقق من صحة الصياغة قبل إرسال البيانات إلى API أو استخدامها في التطبيق.

أخطاء شائعة في JSON

استخدم علامات اقتباس مزدوجة للمفاتيح والنصوص، ولا تضع فاصلة بعد آخر عنصر. JSON لا يقبل التعليقات أو القيم غير القياسية مثل undefined وNaN. رسالة الخطأ وموقعها التقريبي يعتمدان على المتصفح ومحرك JavaScript.

الأسئلة الشائعة

هل يتم إرسال بياناتي إلى الخادم؟

لا، تتم قراءة JSON وتحويله في المتصفح فقط.

هل تدعم الأداة الملفات؟

يمكنك لصق المحتوى ثم تنزيل النتيجة كملف JSON بعد نجاح المعالجة.

هل إصلاح الأخطاء تلقائي؟

الأداة تتحقق من الصياغة وتعرض رسالة الخطأ، لكنها لا تخمّن تعديلات قد تغيّر معنى البيانات.
