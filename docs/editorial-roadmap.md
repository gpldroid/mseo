## Article template requirements

Every new article should include:
- One unique title and meta description written for search intent.
- Canonical URL, Open Graph metadata, and a meaningful H1.
- A short introduction explaining the reader's goal.
- A clear H2/H3 outline, practical steps or examples, and limitations where relevant.
- Internal links to a parent category and 2–4 related articles where available.
- Sources for claims about changing products, prices, releases, or standards.
- Last-updated date only when the article was actually reviewed.
- No invented tests, fake ratings, or unsupported claims.

## Publishing priorities

### Phase 1 — foundation
- Apply one shared design system across home, category, legal, and article pages.
- Fix navigation labels, breadcrumbs, typography, icons, and mobile layouts.
- Validate all local links, canonical URLs, sitemap entries, and metadata.

### Phase 2 — useful content
- Review existing articles for overlap and assign each one a single primary topic cluster.
- Improve thin or repetitive introductions; remove filler.
- Add practical code snippets, screenshots where helpful, and source links.
- Build internal links between category pages and related guides.

### Phase 3 — quality and growth
- Add automated checks for broken internal links, missing descriptions, duplicate titles, and missing H1s.
- Track real search queries and improve articles based on evidence.
- Publish new content only when it adds practical value beyond existing pages.
