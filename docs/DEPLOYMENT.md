# النشر عبر GitHub Pages

## المنصة المعتمدة

يُنشر FastSEO عبر **GitHub Pages** من خلال GitHub Actions. النطاق العام هو:

- https://fastseo.site/

لا تستخدم Netlify أو منصة نشر أخرى لهذا المشروع دون موافقة صريحة.

## سير العمل

ملف سير العمل: `.github/workflows/deploy.yml`

عند فتح Pull Request إلى `main`، ينفذ GitHub Actions مرحلة البناء والتحقق. لا تُنشر تغييرات Pull Request تلقائياً.

عند الدفع إلى `main` أو تشغيل سير العمل يدوياً، ينفذ المسار:

1. checkout للمستودع.
2. تثبيت Hugo Extended وNode.js 22.
3. تنفيذ `npm install --no-audit --no-fund`.
4. تنفيذ `npm run build:css`.
5. توليد ملفات Hugo من مصادر المحتوى عبر `node scripts/prepare-content.mjs`.
6. بناء الموقع إلى `dist/` باستخدام `hugo --minify --destination ./dist`.
7. فحص المخرجات بواسطة `node scripts/verify-build.mjs ./dist`.
8. رفع المخرجات ونشرها عبر إجراءات GitHub Pages.

## ما الذي يتحقق منه الفحص؟

يتحقق `scripts/verify-build.mjs` من وجود الصفحة الرئيسية وSitemap وrobots.txt والأيقونات وملف manifest وملفات الإعلانات والتحقق والتتبع، ومن وجود حزم CSS وJavaScript ووسوم SEO الأساسية، ومخرجات المقالات والصفحات وروابط المقالات في Sitemap.

نجاح هذا الفحص يؤكد سلامة الشروط البرمجية التي يغطيها السكربت، لكنه لا يغني عن فحص بصري للموقع المنشور أو اختبار الروابط من المتصفح.

## قائمة تحقق بعد النشر

- افتح الصفحة الرئيسية على النطاق العام.
- افتح عدة مقالات وصفحات أدوات.
- افتح صفحات التصنيفات وتأكد من ظهور المقالات الصحيحة.
- اختبر الصور في المقالات والبطاقات ومعاينة المشاركة الاجتماعية.
- تحقق من `/sitemap.xml` و`/robots.txt`.
- راجع سجل GitHub Actions وتأكد من نجاح مرحلتي البناء والنشر.
- لا تعلن اكتمال النشر قبل التحقق من عنوان GitHub Pages المنشور.

## استكشاف الأخطاء

- **فشل تجهيز المحتوى:** تحقق من صحة JSON في `data/articles.json` ووجود ملفات HTML المشار إليها في `migration/source/`.
- **مقال أو صفحة غير موجودة:** تحقق من slug ومسار الملف ثم أعد تشغيل `scripts/prepare-content.mjs`.
- **صورة مفقودة:** تحقق من مسار الصورة ووجود الملف في المستودع، ثم راجع حقول `image` و`socialImage`.
- **فشل التحقق:** اقرأ رسائل `scripts/verify-build.mjs`؛ لا تتجاوز الفحص بإزالة الشروط دون فهم سبب الفشل.
- **فشل النشر:** راجع سجل GitHub Actions وإعدادات Pages وبيئة `github-pages`.
