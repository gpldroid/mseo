# معيار محتوى الأدوات الجديدة في MSEO

هذا المعيار إلزامي عند إنشاء أي أداة جديدة أو إجراء تحسين جوهري على أداة قائمة.

## قواعد السلامة والتوافق
- حافظ على تصميم الموقع الحالي، وتوكنات CSS المشتركة، والترويسة والتذييل ومسارات التنقل.
- لا تعدّل وظائف الأدوات الأخرى أو ملفات CSS/JavaScript المشتركة من أجل إضافة المحتوى وحده.
- افصل المحتوى التوضيحي عن منطق الأداة؛ لا تغيّر معرّفات DOM أو معالجات الأحداث أو أسماء الدوال التي تعتمد عليها الوظيفة.
- اختبر روابط الأدوات ذات الصلة، واستجابة الصفحة على الشاشات الصغيرة، وإمكانية الوصول الأساسية.
- لا تدّعِ أن الملفات تُعالج محليًا أو أن الخدمة خاصة إلا إذا كان ذلك صحيحًا فعليًا.

## متطلبات المحتوى لكل أداة
1. عنوان H1 واضح يصف المهمة، ووصف افتتاحي يشرح الفائدة.
2. وصف SEO فريد ودقيق في meta description، مع عنوان صفحة ملائم ورابط canonical صحيح.
3. تعليمات استخدام مرقّمة ومطابقة للوظائف الفعلية.
4. شرح للمخرجات أو الصيغ والقيود والأحجام المدعومة.
5. حالات استخدام ونصائح عملية مرتبطة بالأداة، دون حشو الكلمات المفتاحية أو وعود SEO غير المثبتة.
6. قسم أسئلة شائعة من 3 أسئلة على الأقل، بإجابات مفيدة ومطابقة للسلوك الفعلي.
7. روابط داخلية سياقية إلى أدوات أو صفحات موجودة بالفعل، دون إنشاء أدوات مكررة.
8. بيانات منظمة فقط عندما تكون صحيحة ومتوافقة مع المحتوى الظاهر، ودون إضافة FAQ schema آليًا إذا لم تكن الإجابات ظاهرة للمستخدم.
9. توضيح الخصوصية وحدود الأداة ومتطلبات الخطوة التالية بصدق.
10. استخدام العربية الفصحى الواضحة مع مراعاة اتجاه RTL عند ملاءمته.

## قائمة تحقق قبل طلب الدمج
- [ ] لم تتغير وظائف JavaScript أو CSS أو الأدوات غير المستهدفة.
- [ ] المحتوى التوضيحي والأسئلة الشائعة ظاهر ومطابق للأداة.
- [ ] لا توجد روابط داخلية مكسورة أو وعود غير دقيقة.
- [ ] تعمل الصفحة على الهاتف وسطح المكتب وتبقى منسجمة مع التصميم الحالي.
- [ ] اجتياز `npm test` وفحوصات المستودع المتاحة.
